# Roadmap

This roadmap describes direction, not a release promise. Priorities can change
as the research preview produces evidence.

## Preview foundations

- reproducible single-node setup and demo workflow;
- stable credential bootstrap and safer local secret storage;
- documented public JSON-RPC contracts and compatibility policy;
- bounded migrations, backup/restore guidance, and release packaging;
- clearer observability for agent recovery, blocked work, and authority state.

## Evaluation themes

- durable multi-agent coordination across restarts;
- shared-memory quality, invalidation, and provenance;
- governed project/branch/review workflows;
- resource, budget, and tool-policy enforcement;
- deterministic replay and evidence for autonomous decisions.

## Before a stable release

- define supported deployment and upgrade paths;
- complete threat modeling and external security review;
- establish versioned API/schema compatibility guarantees;
- publish performance and failure-recovery measurements;
- document real-world integrations based on reproducible public examples.

Track concrete work in GitHub Issues. Adoption and maintenance history will be
reported only when there is genuine public evidence.
