# Support

Rhizome Runtime is a research preview without guaranteed support or response
times.

- Use GitHub Issues for reproducible bugs and focused feature proposals.
- Use the documentation and existing issues before opening a question.
- Include the commit, operating system, Go version, command, expected result,
  and sanitized error output.
- Never include API keys, access tokens, workspace passwords, private source,
  databases, or unredacted logs.

Security reports belong in the private channel described in
[SECURITY.md](SECURITY.md).
